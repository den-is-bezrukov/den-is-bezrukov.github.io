# den-is-bezrukov.github.io

Denis Bezrukov's portfolio page: static HTML (no build), two pages. `index.html` is the hub: summary and a short preview of each project. `cases/index.html` holds the full texts, one `<article>` per project with the same id as its preview (`cases/#umo`), sections as `<h3>`; once a project's full text exists, its preview title and its entry in the project list at the top of the home page link there instead of to the preview. Both pages share `style.css` and the Typograf setup in `typograf-ru.js`. Deployed to GitHub Pages only on his word. It is his user site: the GitHub repository is `den-is-bezrukov/den-is-bezrukov.github.io`, the page lives at `den-is-bezrukov.github.io`, and the resume links to cases by their ids (`den-is-bezrukov.github.io/#umo`), so don't rename the ids. Texts are Russian; answer him in Russian.

- Each project preview is an `<article>` with a title, a grey line (client · role · period), two or three short paragraphs and a credits line. Write like Maxim Ilyakhov: past-tense verbs, facts and numbers, no self-praise, his honest share. Who did what comes from the Behance case credits; don't widen his role beyond them.
- Layout is deliberately default, like a Claude artifact or Notion page: Inter (the variable InterVariable.woff2 from the Inter 4.1 release, kept in `fonts/` with its licence, so every glyph is there; the optical size axis gives big headings Inter Display's shapes by themselves), one 680px column, spacing instead of dividers (base 16px, every size and gap a whole step of it in rem: headings 3 / 2rem set solid (2 / 1.5rem on phones) and bold in the text at 600, the intro under the name 1.25rem, text and grey service lines 1rem on a 1.6 line, the grey at 500; every margin and padding from the spacing scale `--space-050`…`--space-800`, named by rem × 100: 800 between projects (600 on phones), 300 between groups, 150 between paragraphs, 050 between list items), black and white backgrounds with text at 90% black or white (#1a1a1a / #e6e6e6), grey #808080 on white, text at 65% in the dark theme.
- Non-breaking spaces are placed in the browser by Typograf (`typograf.min.js`, 7.8.0, kept next to the page; the script at the end of the page applies his `ru-typograph` rules, keeps hyphenated words and Latin names (CSS Design Awards) whole and never leaves the first word of a sentence or of a clause after a comma alone at a line end), so don't type `&nbsp;` into the copy yourself: the only ones in the files are those Denis sets by hand in edit mode.
- Images from client work: only what is already public on Behance; TXN Pro and UMO need his say first.
- Edit mode for the copy: `_edit/Править.command` (or `python3 _edit/server.py`) serves the site at localhost:8765 for viewing; with `?edit` in the address every heading and paragraph of that page is editable in place, and saves each change straight into that page's file. Lines break as on the site: Typograf runs in edit mode too and lays a block out again when you leave it, and the editor strips its non-breaking spaces and word spans before saving. There Enter (and Shift+Enter) sets a line break (`<br>`; nothing in rows of links and breadcrumbs), ⌘Enter adds an empty paragraph below the block wherever the caret is, Backspace at a paragraph's start joins it to a plain paragraph above (an empty one is removed), ⌥Space a non-breaking space (saved as `&nbsp;`), ⌘K or pasting an address over selected words a link, and ⌘-click follows a link (the site's own pages open in edit mode too). A toolbar of plain text in groups with a 6% line between them sits above the block with the caret, on its left (held at the window's top once the block's start scrolls above it): § adds a section (cases) or a project from a template after asking its anchor (home); then the block's style (H1, H2, Lead, Body, Meta, List; H3 only on a page that has section headings; ⌥⌘1/2/3/0/8, Lead and List have no shortcut), its line layout (Pretty, the site's default, or Balance, the `balance` class; the label names the current one) and ↓ ↑ to move it (⌘⇧↑/↓; a project title moves the whole project and its entry in the project list). List is one block, a `<ul>` with an `<li>` per item: Enter in an item makes the next one (Shift+Enter breaks the line inside it), Enter in an empty last item leaves the list for a new paragraph, Backspace at an item's start joins it to the item above; switching a block into List or out of it turns its lines into items and back. The shortcuts panel is out for now. ⌘Z/⇧⌘Z step through saves. Saves go to the server one at a time, each checked against what the file should hold; every write keeps the version it replaces in `_edit/history/` (git-ignored, the last 200 per page), and undo refuses once the file was changed from outside the editor. `_edit/` starts with an underscore, so GitHub Pages doesn't publish it.
