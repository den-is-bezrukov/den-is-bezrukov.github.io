# Проекты Дениса Безрукова

Главные проекты дизайнера Дениса Безрукова: что в них делал он, а что команда. Адрес: den-is-bezrukov.github.io, на кейс ведёт ссылка с его меткой, например den-is-bezrukov.github.io/#umo.

Тексты лежат в `index.html`, вид страницы в `style.css`, неразрывные пробелы расставляют `typography.js` и `typograf.min.js`. Сборки нет: файл открывается в браузере как есть.

Тексты написаны по правилам Максима Ильяхова: глагол, факт, честная доля участия, одна деталь ремесла. Факты те же, что в резюме; кто что делал — по титрам кейсов на Behance.

## Как поправить текст

Один раз:

1. Поставить [BBEdit](https://www.barebones.com/products/bbedit/). После пробного месяца он остаётся бесплатным, этого хватает.
2. В GitHub Desktop: File → Add Local Repository… → папка `Documents/GitHub/cases`.
3. Там же: GitHub Desktop → Settings… → Integrations → External Editor: BBEdit.

Каждый раз:

1. GitHub Desktop: Fetch origin, а если кнопка стала Pull origin, нажать и её. Так подтянутся правки, сделанные в другом месте.
2. Repository → Open in BBEdit, открыть `index.html`, поправить, ⌘S.
3. Открыть `index.html` в браузере или обновить его (⌘R) и посмотреть.
4. GitHub Desktop: слева видна правка, красным и зелёным. Внизу в Summary коротко написать, что поменяли, и нажать Commit to main.
5. Push origin. Через минуту-две правка на сайте.

Где что в `index.html`:

- кейс лежит между `<article id="…">` и `</article>`: заголовок в `<h2>`, серая строка в `<p class="meta">`, абзацы в `<p>`, титры в `<p class="credits">`;
- ссылка пишется так: `<a href="https://…">текст</a>`;
- `id` у кейсов не менять: на них ведут ссылки из резюме;
- неразрывные пробелы ставить не надо, их расставит типограф в браузере.

Если что-то пошло не так: до коммита правой кнопкой по файлу в GitHub Desktop → Discard Changes. После пуша: History, правой кнопкой по коммиту → Revert Changes in Commit, потом Push origin.
