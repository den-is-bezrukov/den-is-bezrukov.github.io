# Проекты Дениса Безрукова

Главные проекты дизайнера Дениса Безрукова: что в них делал он, а что команда. Две страницы без сборки: `index.html` — главная с коротким рассказом о каждом проекте, `cases/index.html` — полные тексты. Открыть файл в браузере или выложить на GitHub Pages. Адрес: den-is-bezrukov.github.io, на проект ведёт ссылка с его меткой, например den-is-bezrukov.github.io/#umo, на полный текст — den-is-bezrukov.github.io/cases/#umo.

Править тексты прямо на странице: открыть `_edit/Править.command`. Там Enter — новый абзац, Backspace в начале абзаца склеивает его с предыдущим, Shift+Enter — перенос строки (держится только на компьютере), ⌥Пробел — неразрывный пробел, ⌘K или ⌘V с адресом поверх выделенных слов — ссылка, кнопка «Ровные строки» выравнивает строки абзаца.

Тексты написаны по правилам Максима Ильяхова: глагол, факт, честная доля участия, одна деталь ремесла. Факты те же, что в резюме; кто что делал — по титрам кейсов на Behance.
