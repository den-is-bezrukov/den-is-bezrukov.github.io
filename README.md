# Проекты Дениса Безрукова

Главные проекты дизайнера Дениса Безрукова: что в них делал он, а что команда. Одна страница, `index.html`, без сборки: открыть файл в браузере или выложить на GitHub Pages. Адрес: den-is-bezrukov.github.io, на кейс ведёт ссылка с его меткой, например den-is-bezrukov.github.io/#umo.

Тексты написаны по правилам Максима Ильяхова: глагол, факт, честная доля участия, одна деталь ремесла. Факты те же, что в резюме; кто что делал — по титрам кейсов на Behance.
